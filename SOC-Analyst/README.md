# SOC Analyst — Detection, Adversary Tactics & Incident Handling

This directory contains the independent 77-lab SOC curriculum. The course progresses from SOC foundations through network, Windows/Active Directory, Linux, SIEM, adversary tactics, endpoint/DFIR, threat hunting, cloud/identity security operations, incident handling, and a final enterprise SOC capstone.

## Course Authority

Canonical lab numbering and titles are controlled by the authoritative curriculum under `Curriculum/SOC-Analyst/`. Completion state is controlled by the SOC course-progress file.

Tools are introduced and taught before independent use. Operational claims require verified systems, telemetry paths, and evidence.
