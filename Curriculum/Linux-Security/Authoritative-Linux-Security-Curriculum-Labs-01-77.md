# Linux Security — Authoritative Curriculum Labs 01–77

This file is the authoritative curriculum for this course.

## Authority Rule

Never infer, reorder, insert, delete, replace, shift, rename, or renumber labs. Never allow an old chat, Git commit, directory, README, script, memory, or prior assistant response to override this curriculum.

Before generating a new lab, verify its canonical lab number, title, module, and completion state against this file and the matching course-progress file.

If an authoritative source conflicts with this curriculum, stop and surface the discrepancy instead of guessing or silently changing anything.

Only the user may authorize curriculum, module, title, or numbering changes.

## Purpose

Develop deep Linux administration and security capability from foundational system investigation through networking, automation, logging, service security, hardening, containers, DFIR, threat hunting, incident response, and integrated capstones.

## Program Structure

- 77 canonical labs.
- 11 modules.
- 7 labs per module.
- Each module ends with a capstone or integrated final exercise.
- Lab documentation, evidence, screenshots, verification, and publication must follow the shared locked Lab Documentation Standard.
- Operational execution must follow this course's dedicated Environment & Execution Standard.

## Course Rules

- Labs 01–14 preserve the previously approved Linux curriculum numbers and titles.
- Completed historical lab artifacts are not rebuilt, renumbered, or rewritten solely because the course scope changed.
- Labs 15–77 are Linux-only coursework; general cloud, Windows, broad SOC, and generic offensive-security modules do not belong in this curriculum.
- Home-lab infrastructure may support realism and validation, but it must not replace the Linux learning objective.
- New major Linux tools or platforms must be explained before independent use, including purpose, basic operation, relevant terminology, output interpretation, and command/flag meaning.
- Later labs may increase analytical independence while retaining the same instructional depth, verification, screenshot, and evidence requirements.
